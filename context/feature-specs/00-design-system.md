# Design System

We're implementing the project's design system.

## Objective

Set up the shared UI foundation that every future feature will use.

## Tasks

Install and configure:

- shadcn/ui
- lucide-react

Configure:

- Tailwind CSS
- CSS variables
- Theme provider
- Dark mode only

Create:

- lib/utils.ts
- cn() helper

Install the following shadcn components:

- Button
- Card
- Dialog
- Dropdown Menu
- Input
- Label
- Select
- Separator
- Sheet
- Skeleton
- ScrollArea
- Tabs
- Textarea
- Tooltip
- Avatar
- Badge
- Alert
- AlertDialog
- Checkbox
- Command
- Popover
- Table

Do not modify generated `components/ui/*` files unless absolutely necessary.

## Styling

Use the colors defined in `globals.css`.

Ensure every component matches the platform theme.

Do not introduce custom colors.

Do not use inline styles.

Use Tailwind utilities.

## Icons

Use only `lucide-react`.

## Accessibility

Ensure every component remains accessible.

Do not remove ARIA attributes generated by shadcn.

## Validation

When finished verify:

- All components compile.
- No TypeScript errors.
- No ESLint errors.
- No hydration warnings.
- No light theme appears.
- `cn()` works correctly.
- Components render correctly.
